# tools/

Вспомогательные скрипты, утилиты сборки, экспорта и автоматизации пайплайна **Shoes Villains**.

## Что здесь лежит

- Скрипты валидации конфигов и синхронизации `shared/`
- Утилиты пакетирования, экспорта ассетов из `art_src/` в `client/` и автоматизации сборок
- Локальные вспомогательные инструменты разработки

## Что сюда не кладётся

- Игровой рантайм-код клиента (`client/`) или сервера (`server/`)
- Секреты, токены доступа и временные артефакты сборки
