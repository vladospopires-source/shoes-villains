# client/

Клиентская часть игры **Shoes Villains** на движке **Godot 4**.

## Что здесь лежит

- Конфигурация проекта `project.godot` (будет добавлена позже)
- Сцены (`.tscn`), ресурсы (`.tres`) и клиентские скрипты
- Готовые экспортированные игровые ассеты (спрайты, тайлсеты, аудио, шрифты), используемые движком

## Что сюда не кладётся

- Серверная логика и база данных (это зона `server/`)
- Рабочие исходники графики и звука — `.aseprite`, `.psd`, проекты DAW (они хранятся в `art_src/`)
- Утилиты сборки и вспомогательные скрипты вне рантайма (они лежат в `tools/`)
