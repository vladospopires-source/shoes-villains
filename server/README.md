# server/

Серверная часть игры **Shoes Villains** (стек и архитектура будут выбраны позже).

## Что здесь лежит

- Авторитетная игровая логика, сетевой транспорт и обработка сессий
- Конфигурация серверного окружения и миграции/хранилище (при необходимости)

## Что сюда не кладётся

- Клиентский код, сцены и рендеринг (это зона `client/`)
- Игровые ассеты и рабочие исходники арта (`client/` и `art_src/`)
- Общие контракты и таблицы баланса в сыром виде — они выносятся в `shared/`
