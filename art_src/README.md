# art_src/

Рабочие исходники арта, анимаций и аудио для **Shoes Villains**, хранящиеся вне проекта Godot.

## Что здесь лежит

- Исходники спрайтов, тайлсетов и UI (`.aseprite`, `.psd`, `.kra`, `.svg` и т.п.)
- Проекты DAW, необработанные записи звука и музыки
- Промежуточные референсы и черновики визуала

## Что сюда не кладётся

- Финальные экспортированные ассеты, готовые к импорту в движок — они экспортируются в `client/`
- Исходный код и скрипты автоматизации экспорта (скрипты — в `tools/`)
