# shared/

Общие контракты, схемы данных и таблицы баланса, единые для клиента (`client/`) и сервера (`server/`).

## Что здесь лежит

- Схемы сетевых сообщений и протоколы взаимодействия клиент–сервер
- Общие таблицы баланса, константы и декларативные конфиги (JSON/YAML/CSV и т.п.)
- Описания общих структур данных

## Что сюда не кладётся

- Платформозависимая или движковая логика клиента (`client/`)
- Серверная инфраструктура, секреты и код хранения данных (`server/`)
