# docs/

Игровая и техническая документация проекта **Shoes Villains**.

## Что здесь лежит

- GDD (Game Design Document) и концепция геймплея
- Архитектурные решения и схемы ([ARCHITECTURE.md](ARCHITECTURE.md))
- Разборы референсов и прототипов
- Спецификации сетевых протоколов и форматов данных

- Исходный код клиента, сервера или утилит
- Бинарные игровые ассеты и рабочие исходники графики/звука
